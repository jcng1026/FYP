# Ollama (local LLM for Kertas 2 natural-language feedback) is a NATIVE
# application, NOT a pip package - it cannot be installed by `pip install`.
# Install it and download the model with these terminal commands
# (or just run:  powershell -ExecutionPolicy Bypass -File scripts\setup_ollama.ps1):
#
#   winget install --id Ollama.Ollama -e     # install the Ollama runtime
#   ollama pull llama3.2                      # download the feedback model (~2 GB)
#
# If winget is unavailable, download the installer from https://ollama.com/download
# and then run `ollama pull llama3.2`. MarkAssist starts Ollama automatically at
# launch. Without Ollama, feedback falls back to built-in offline templates and
# marking, review and results are unaffected.
